## 4. 実施内容

現行レビュー手順では、宣言から赤試験への対応表を作る場合に次を必須とする。

- `red_verification_contract.version`を2にする。
- `red_now: true`の各試験へ、予定した失敗理由`expected_failure_reason`を持たせる。
- `verify_red=True`と`minimum_red_contract_version=2`を同時に指定する。
- 結果全体が`status: passed`であり、準備失敗、理由違い、結果不明、主張不一致が0件であることを確認する。

既存試験一件では、同じ一関数内で次の二入力を別々に作り、それぞれ固有の所見を確認する。

- 試験file一覧を残し、宣言だけを空にする。
- 宣言を残し、試験file一覧だけを空にする。
