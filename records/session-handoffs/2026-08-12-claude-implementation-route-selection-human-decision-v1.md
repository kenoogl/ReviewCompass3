## 1. 選択の意味

Codex主担当が依頼と進行管理を行い、Claudeが実装だけを担当し、反対側のCodexモデルが独立レビューする
最小経路の範囲設計と事前確認を開始する。

既存の「操縦者別連携 第2縦切り」は、同形の指示文所見が2周続いた場合のHuman裁定、再監査、停止を扱う
名称として予約済みである。今回選択した外部実装委譲は、これと混同せず
「Claude実装委譲経路 第1縦切り」と呼ぶ。既存の第2縦切り要求は変更しない。

## 2. 本裁定が認める範囲

- 現行文書、Claude Code CLI 2.1.220、公式権限仕様、既存の信頼済み入口を調査する。
- 高危険度の範囲固定案を作成し、機械検査、指示文監査、指示文判定、独立範囲レビューを行う。
- 所見があれば、Humanへ採否を依頼する。

## 3. 本裁定が認めない範囲

- 失敗する受入試験の作成、製品実装、管理者配置の変更。
- Claudeの実装用process起動、認証変更、外部送信。
- ReviewCompass3のrepository内容、秘密情報、利用者情報をAnthropicへ送ること。
- Claudeへ読取、編集、書込、Bash、MCP、Web、Chrome、別agentなどの道具を許可すること。
- Humanによる範囲、所見採否、実装開始、外部送信、段完了の判断をモデルが代理すること。

範囲レビューが合格しても、失敗する受入試験の作成と実装開始は別のHuman承認とする。実装が完了しても、
Claudeを使う確認運転と外部送信は、送信内容と権限へ束縛した別のHuman承認とする。
