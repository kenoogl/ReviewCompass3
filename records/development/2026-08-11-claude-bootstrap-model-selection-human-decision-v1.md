# 無工具Claude疎通 モデル選択Human裁定 v1

- 日付：2026-08-11
- 対象：`codex-pilot-no-tool-claude-bootstrap`
- 状態：`approved`

## 裁定

1. 要求モデルは固定値ではなく、実行ごとにHumanが指定する。
2. 今回の要求モデルはClaude Fable 5、正式識別子は`claude-fable-5`とする。
3. Fable 5を要求した場合に許容する実応答モデルは、次の閉じた集合とする。
   - `claude-fable-5`
   - `claude-opus-5`
   - `claude-opus-4-8`
4. 要求モデルと許容実応答モデル集合を、送信目録、Human送信承認、一回限りtokenへ束縛する。
5. 実行結果には、要求モデルとpayloadごとの実応答モデルを分けて保存する。
6. 実応答モデルが許容集合外、空、または機械的に特定不能なら成功扱いにしない。

## 差し替える判断

- Fable 5だけとの完全一致を要求する案は採用しない。
- Opus 5だけへ固定する案は採用しない。
- Claude Codeの既定モデルをHuman指定の代わりに使う案は採用しない。

## 外部送信境界

本裁定は、試験、実装、送信目録、完了レビューの訂正を認める。Claudeの起動、認証操作、外部送信は、
訂正後の実物へ束縛した一回限りのHuman送信承認まで認めない。
